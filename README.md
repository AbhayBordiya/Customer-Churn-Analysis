## 📖 About the Project

This project analyzes customer data to understand **why customers churn** and which customer characteristics are associated with a higher level of churn.

The project focuses on **data cleaning, preprocessing, exploratory data analysis (EDA), and visualization** using Python. Different customer attributes such as tenure, contract type, payment method, internet service, and additional services were analyzed against the `Churn` variable.

The goal is to turn raw customer data into clear, easy-to-understand insights through visual analysis.

---

## 🎯 Project Objectives

- Clean and prepare the customer dataset for analysis.
- Handle missing and incorrectly formatted values.
- Convert columns into appropriate data types.
- Explore customer churn patterns using statistical and graphical analysis.
- Identify customer segments that show noticeable differences in churn.
- Present findings through clear and meaningful visualizations.
